# Lemin en C

Version C du projet Lemin Python. Le programme lit une carte depuis l'entree standard, construit le graphe residuel, selectionne les chemins utiles et simule le deplacement des fourmis.

## Compilation

```sh
make
```

## Execution

```sh
./lem-in < map.txt
```

Le projet utilise `libft/libft.a`, construite automatiquement par le Makefile racine. Les commandes disponibles sont `clean`, `fclean` et `re`.
